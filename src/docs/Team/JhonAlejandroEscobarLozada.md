## Carta de Presentación

Jhon Alejandro Escobar Lozada es Backend Software Engineer & API Developer en NexusOdonto, especializado en diseño, desarrollo y documentación de APIs RESTful. Su enfoque en seguridad de servicios y arquitectura de servidores ha garantizado la robustez y confiabilidad de la comunicación entre componentes del sistema.

### Responsabilidades Clave

- **Diseño de APIs**: Diseño y desarrollo de APIs RESTful siguiendo mejores prácticas y estándares de la industria.
- **Documentación Técnica**: Creación de documentación clara y completa para todos los endpoints y servicios.
- **Seguridad de Servicios**: Implementación de medidas de seguridad, autenticación y autorización en APIs.
- **Arquitectura de Servidores**: Configuración y optimización de servidores para máximo rendimiento y disponibilidad.

### Tecnologías Clave

- **API Development**: ASP.NET Core Web API, Swagger/OpenAPI, Postman
- **Seguridad**: JWT, OAuth 2.0, HTTPS, CORS, Rate limiting
- **Servidores**: IIS, Nginx, Docker containers, Azure App Service
- **Monitoreo**: Application Insights, ELK Stack, Health checks

### Visión

"Una API bien diseñada es la columna vertebral de cualquier sistema moderno; me enfoco en crear servicios que sean intuitivos, seguros y bien documentados."
