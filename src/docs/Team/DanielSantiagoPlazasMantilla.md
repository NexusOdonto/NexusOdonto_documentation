## Carta de Presentación

Daniel Santiago Plazas Mantilla es Backend Software Engineer & System Architect en NexusOdonto, especializado en modelos de datos, optimización de consultas y patrones de arquitectura de software. Su expertise en diseño de sistemas complejos e integración de microservicios ha sido fundamental para la escalabilidad y mantenibilidad de la plataforma.

### Responsabilidades Clave

- **Modelos de Datos**: Diseño de modelos de datos eficientes y normalizados para el sistema odontológico.
- **Optimización de Consultas**: Análisis y optimización de consultas complejas para máximo rendimiento.
- **Patrones de Arquitectura**: Implementación de patrones de arquitectura de software escalables y mantenibles.
- **Integración de Microservicios**: Diseño y coordinación de la integración entre microservicios del sistema.

### Tecnologías Clave

- **Arquitectura**: Microservices, Service Mesh, Event Sourcing, CQRS
- **Datos**: SQL Server, PostgreSQL, Redis, Elasticsearch
- **Patrones**: Repository, Unit of Work, Factory, Strategy patterns
- **DevOps**: Docker, Kubernetes, CI/CD, Infrastructure as Code

### Visión

"La arquitectura de software correcta puede hacer la diferencia entre un sistema que escala y uno que colapsa; me enfoco en crear estructuras sólidas desde el inicio."
