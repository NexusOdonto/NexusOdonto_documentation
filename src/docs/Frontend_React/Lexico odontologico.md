# Léxico odontológico

Vocabulario del negocio: las palabras que se usan en una odontología, qué
significan, y cómo las dice el paciente frente a cómo las dice el profesional.

---

## 1. Cómo se nombra la boca

### 1.1 Los dientes por tipo

- **Incisivos** — los de adelante, sirven para cortar
- **Caninos** — los colmillos
- **Premolares**
- **Molares** — las muelas
- **Cordales** — las muelas del juicio, el tercer molar

### 1.2 Partes de un diente

- **Corona** — lo que se ve
- **Raíz** — lo que está dentro del hueso
- **Esmalte** — la capa dura de afuera
- **Dentina** — la capa que está debajo del esmalte
- **Pulpa** — el nervio
- **Cuello / cervical** — donde el diente se encuentra con la encía
- **Ápice** — la punta de la raíz

### 1.3 Las caras del diente

Es lo que más se usa a diario, porque toda condición se registra sobre una cara.

- **Oclusal** — la de masticar, en las muelas
- **Incisal** — el filo, en los dientes de adelante
- **Vestibular** — la que da al cachete
- **Lingual** — la que da a la lengua (dientes de abajo)
- **Palatina** — la que da al paladar (dientes de arriba)
- **Mesial** — hacia el centro de la boca
- **Distal** — hacia atrás

### 1.4 Ubicación general

- **Arcada superior / arcada inferior**
- **Cuadrantes** — la boca se divide en cuatro
- **Línea media**
- **Anteriores** — los dientes de adelante
- **Posteriores** — las muelas

### 1.5 Los tres momentos de la dentición

- **Dentición temporal** — los dientes de leche
- **Dentición permanente** — los definitivos
- **Dentición mixta** — cuando conviven las dos, típico en niños

## 2. Lo que se le encuentra a un paciente

- **Caries**
- **Placa bacteriana**
- **Sarro / cálculo**
- **Gingivitis** — encía inflamada
- **Periodontitis** — cuando ya afecta el hueso
- **Absceso**
- **Fístula**
- **Bruxismo** — apretar o rechinar los dientes
- **Maloclusión** — los dientes no cierran bien
- **Apiñamiento** — dientes montados
- **Diastema** — espacio entre dientes
- **Sensibilidad**
- **Halitosis** — mal aliento
- **Movilidad** — diente flojo
- **Desgaste / atrición**
- **Fractura**
- **Retracción gingival** — encía que se corre

### 2.1 Estados en que puede estar un diente

- **Presente**
- **Ausente**
- **Extraído**
- **Erupcionando** — está saliendo
- **Incluido / retenido** — no salió, está atrapado en el hueso
- **Exfoliado** — se cayó solo, típico de los dientes de leche

## 3. Lo que se le hace

- **Valoración**
- **Profilaxis** — limpieza
- **Detartraje** — limpieza profunda, quitar sarro
- **Obturación** — tapar una caries
- **Endodoncia** — tratamiento de conductos
- **Exodoncia** — sacar el diente
- **Curetaje** — limpieza por debajo de la encía
- **Corona**
- **Puente**
- **Prótesis**
- **Implante**
- **Carilla**
- **Blanqueamiento**
- **Sellante**
- **Férula / placa** — para el bruxismo
- **Brackets**
- **Alineadores**
- **Retenedores**

## 4. La palabra del paciente vs. la palabra del odontólogo

Lo más importante del documento: **la página le habla al paciente, pero el
sistema guarda en lenguaje clínico.**

| Dice el paciente | Dice el odontólogo |
|---|---|
| Muela | Molar |
| Muela del juicio | Cordal / tercer molar |
| Colmillo | Canino |
| Calza, tapadura | Obturación / resina |
| Me taparon la muela | Se obturó |
| Limpieza | Profilaxis |
| Sarro | Cálculo dental |
| Matar el nervio | Endodoncia |
| El nervio | La pulpa |
| Sacar la muela | Exodoncia |
| Frenillos, brackets | Ortodoncia |
| Caja, dentadura postiza | Prótesis total |
| Encías sangrantes | Gingivitis |
| Diente flojo | Movilidad dental |
| Diente picado | Lesión cariosa |

> **Regla práctica:** en la web se escribe *"limpieza dental"*; en la historia
> clínica se escribe *"profilaxis"*. Si se invierte, el paciente no entiende la
> página y el odontólogo no confía en el sistema.

## 6. Las especialidades

| Especialidad | Qué trata |
|---|---|
| **Odontología general** | Consulta, limpieza, calzas. La puerta de entrada. |
| **Endodoncia** | Tratamiento de conductos (matar el nervio) |
| **Periodoncia** | Encías: gingivitis, periodontitis, curetaje |
| **Ortodoncia** | Brackets, alineadores, retenedores |
| **Odontopediatría** | Niños |
| **Rehabilitación oral** | Prótesis, coronas, puentes (también "prostodoncia") |
| **Implantología** | Implantes dentales |
| **Cirugía oral y maxilofacial** | Cordales, cirugías complejas |
| **Odontología estética** | Blanqueamiento, carillas, diseño de sonrisa |
| **Radiología oral** | Panorámicas, periapicales |
| **Patología oral / Estomatología** | Lesiones de mucosa, diagnóstico |

Las que **siempre** aparecen en una página comercial, porque son las que venden:
general, ortodoncia, estética, implantología y endodoncia.

## 7. Los servicios

Lo que realmente se cotiza y aparece en el tarifario.

**Preventivo**
- Consulta / valoración
- Profilaxis (limpieza dental)
- Detartraje (limpieza profunda)
- Aplicación de flúor
- Sellantes (niños)

**Operatoria**
- Resina / obturación (la "calza")
- Incrustación

**Endodoncia**
- Conducto unirradicular / birradicular / multirradicular
  *(se cobra distinto según el número de raíces)*

**Cirugía**
- Exodoncia simple
- Exodoncia quirúrgica
- Extracción de cordales

**Periodoncia**
- Curetaje / raspaje y alisado radicular
- Cirugía de encía

**Rehabilitación**
- Corona (metal-porcelana, zirconio, emax)
- Puente
- Prótesis total / parcial removible
- Implante dental

**Estética**
- Blanqueamiento (en consultorio / ambulatorio)
- Carillas (resina / porcelana)
- Diseño de sonrisa

**Ortodoncia**
- Brackets metálicos / estéticos / autoligado
- Alineadores invisibles
- Retenedores
- Control mensual

**Otros**
- Radiografía periapical / panorámica
- Placa de bruxismo (férula)

Elementos fijos en toda la página: **botón de WhatsApp flotante**, teléfono en
el header, y el CTA de agendar. En este sector la mayoría de las conversiones
salen de ahí.

## 9. El sentido de todo esto

Todo el negocio, resumido en una frase con estas palabras:

> Se hace una **valoración**, se levanta un **odontograma** para saber qué tiene
> cada diente, de ahí sale un **diagnóstico**, con eso se arma un **plan de
> tratamiento** con su **presupuesto**, el paciente firma el **consentimiento**,
> y se ejecuta en **sesiones** hasta el **control** final.

Esa frase es literalmente el flujo del sistema. Todo lo demás son detalles.
