# Documentación - Brayan Snehyder Castro Velandia

## 1. Introducción

Como parte del trabajo grupal de **NexusOdonto**, mi aporte estuvo enfocado en la elaboración de **prototipos y diseños visuales de la página**.

Para realizar los diseños utilicé principalmente **Google Stitch y Canva**, donde pude crear y modificar diferentes propuestas para definir la apariencia de la aplicación.

## 2. Diseño realizado

Trabajé principalmente en la propuesta visual de la interfaz, buscando que tuviera un diseño moderno, limpio y relacionado con el área odontológica y tecnológica.

En mi parte realicé propuestas para:

- La estructura visual de la página.
- El diseño del login.
- La distribución de los elementos.
- La adaptación de la interfaz al modo oscuro.
- La apariencia y adaptación del logotipo.
- La selección y aplicación de colores.

## 3. Paleta de colores

Para realizar los prototipos utilicé la paleta de colores definida para el proyecto:

| Elemento                             | Color     |
| ------------------------------------ | --------- |
| Color Primario (Botones y Selección) | `#00A8CC` |
| Color Primario Hover                 | `#008B9B` |
| Color Secundario / Acento            | `#66D2B1` |
| Texto Principal / Encabezados        | `#1A3644` |
| Texto Secundario                     | `#64748B` |
| Fondo de Tarjetas / Modales          | `#FFFFFF` |
| Fondo de la Aplicación               | `#F8FAFC` |
| Fondo de Resaltados / Badges         | `#E6F7FA` |
| Bordes y Separadores                 | `#E2E8F0` |

Utilicé estos colores como referencia para mantener una identidad visual uniforme en los diferentes diseños.

## 4. Herramientas utilizadas

### Google Stitch

Utilicé **Google Stitch** para crear los prototipos de la interfaz y probar diferentes propuestas de diseño, distribución y estilos.

### Canva

También utilicé **Canva** para trabajar en elementos gráficos y realizar ajustes visuales relacionados con la presentación del diseño y la identidad gráfica.

## 5. Resultado

Como resultado, desarrollé diferentes **prototipos visuales de la página**, incluyendo propuestas para el login, la interfaz y el modo oscuro.

Mi aporte se centró en la **parte de diseño y prototipado**, sirviendo como referencia visual para la posterior implementación del proyecto por parte del equipo.
