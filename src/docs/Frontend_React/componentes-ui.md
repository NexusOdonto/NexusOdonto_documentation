Documentación del sistema de componentes en React para la interfaz de usuario de **NexusOdonto**.

## Sistema de Tokens

El sistema se basa en tokens CSS expuestos en `tokens.css`:

```css
:root {
  --color-primary: #1E40AF;
  --color-secondary: #E0F2FE;
  --color-tertiary: #10B981;
  --color-neutral-dark: #0F172A;
}
```
